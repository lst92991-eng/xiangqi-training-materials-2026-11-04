## 板端接入约定

- RV1106使用`.rknn`；保持原模型文件，测试程序的模型路径指向新文件。
- 转换工具为RKNN Toolkit2 **1.6.0**，对应项目既有板端运行时1.6.0。不要仅改后缀或未经核对替换运行库。
- 输入为RGB，保持比例letterbox到640×640，补边值114。模型转换已配置mean=0、std=255；按既有RGB字节输入接口接入，避免重复归一化。
- 类别ID顺序固定为`kabnrcpKABNRCP`：黑将、士、象、马、车、炮、卒；红帅、仕、相、马、车、炮、兵。
- 测试采用score=0.50、跨类别NMS IoU=0.45，每个候选框只取最高分的类别。
- 输出是三个sigmoid概率头，stride为8/16/32，每头57个逻辑通道；需要坐标解码、反量化和NMS。ONNX也不是已经解码的最终检测框。
- 标准anchors为`[10,13,16,30,33,23]`、`[30,61,62,45,59,119]`、`[116,90,156,198,373,326]`。原生NHWC输出按查询到的维度、步长、scale和zero-point读取。

固定训练框架为`airockchip/yolov5`提交`23a20ef3e5fa648e765e4a70b30edbfd3aaf8c8c`。PT是该YOLOv5结构的checkpoint，不是新版Ultralytics的通用权重。[模型元数据与各文件哈希](model-v3.json)。

## 数据与训练来源

基于本仓库提交`f2a22937ac4d9737edb451f358131428b1293b22`及`v2026.11.05-local-data`素材Release，ZIP SHA-256为`6a0f9db66603397142285f36339df6e75ca59fc8425d2bdc5c8dff09cad58f1b`。

发布数据中有26张已审核图：s02训练19张、s04验证3张、s03测试4张。逐枚放大/旋转核对发现，每张有一枚黑将和一枚黑象类别对调。训练副本共修正52处，框坐标不变；[逐文件与逐行修改记录](model-v3-label-corrections.json)可追溯。原始素材Release保持原样，未通过修改源包或基准哈希掩盖差异。复用原素材重训时应先核对这些纠错。

从expanded-v1权重出发，先训练80轮；针对首轮测试仍存在的黑将错认，再从真实训练棋子裁片生成128张方向、尺寸、明暗和布局增强图，强化60轮。增强图不是独立实拍或真实棋局；未审核预测草稿、验证图和测试图没有进入训练。最终选择强化阶段第51轮，依据验证组的实际单类别输出错误数和类别分数间隔选模。

首轮测试结果用于定位问题，因此最终测试复查不是一次全新的盲测。标注为助手视觉复核，未经过独立人工审校。

## 补测结果与已知限制

模型交付后保持权重不变，检查了15帧原图（含新增目视核对8帧），每帧重复10轮；再测试615个派生变体。以下是**检测次数**，不代表更多独立实拍样本。

| 范围 | 棋子检测次数/后端 | FP32错认/漏检 | 量化模拟错认/漏检 |
| --- | ---: | ---: | ---: |
| 原图重复10轮 | 4,800 | 0 / 0 | 0 / 0 |
| 随机组合扰动 | 7,200 | 1 / 0 | 6 / 0 |
| 中等扰动 | 8,160 | 19 / 1 | 18 / 1 |
| 强模糊、拖影、缩小等 | 4,320 | 382 / 15 | 388 / 14 |

上述测试均没有额外检测框。同一原图的10轮预测结果完全一致。随机扰动中仍出现红车→红相，FP32置信度约0.92；高置信度不保证身份正确。

量化补测是在PC上使用相同ONNX、校准图及配置重建的模拟环境。重建RKNN与交付RKNN等长，原始SHA-256不同：差异仅为前64字节内14字节，其余字节全部一致；不同字段的语义未据此认定。该模拟不等于交付文件已在真实RV1106上执行通过。

清晰原图表现稳定，但画面模糊、运动拖影、棋子像素尺寸下降后仍可能错认。当前结果不能证明任意棋具、任意光照、任意机位或手部遮挡下100%正确。[完整补测统计、条件与校验信息](model-v3-test-summary.json)。

本次发布只提供模型和说明，板端实测结果需另行记录。
